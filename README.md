## 🚀 Projetos em destaque

### 🧪 Automação de Testes — Projeto TCC

Projeto de automação de testes para uma aplicação de gerenciamento de casos de teste, contemplando testes E2E, de API, acessibilidade e performance.

Aplica práticas como Page Object Model (POM), Fixtures, geração dinâmica de dados, interceptação de requisições, integração contínua e monitoramento de métricas de performance.

**Tecnologias:** Playwright, TypeScript, Postman, Newman, k6, Axe, GitHub Actions, Allure, Grafana e Docker.

### 🌐 Automação de Testes E2E — BugBank

Projeto de automação de testes E2E da aplicação BugBank utilizando Cypress, TypeScript e Behavior-Driven Development (BDD) com Cucumber e Gherkin.

Aplica Page Object Model (POM), centralização de seletores, Data-Driven Testing com Scenario Outline, Test Data Factory, geração dinâmica de dados com Faker.js e execução seletiva de cenários por tags.

Possui pipeline de integração contínua com validação de tipagem, análise estática de código, execução automatizada de testes e publicação de relatórios Allure no GitHub Pages.

**Tecnologias:** Cypress, TypeScript, Cucumber, Gherkin, Faker.js, Allure Report 3, ESLint, Prettier e GitHub Actions.
